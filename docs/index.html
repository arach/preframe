How it works

1 · capture

Start with a raw capture: screen, camera, audio, stills, whatever is available.

2 · shape

The agent makes a first cut and breaks the work into useful pieces: takes, frames, notes, timing, captions, music, treatments.

3 · review

Review the take. Box the rough frame. Leave the note right where the problem happens.

4 · control

Steer pacing, emphasis, music, captions, framing, and treatments. These are real controls, not a blank prompt box.

5 · render

The agent renders another take from that feedback. Keep the one that works.

To run it locally:

git clone github.com/arach/preframe && cd preframe && bun install && bun run dev
