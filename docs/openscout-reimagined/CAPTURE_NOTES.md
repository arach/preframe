## Rejected calibration take

The initial Action app-window request failed because the Simulator window was
447 pixels wide and ScreenCaptureKit rejected the odd output width. A bounded
display retry recorded the background surface because the Simulator was in a
different macOS Space. Those calibration files are not source material. The
canonical take above was captured with the Simulator's native device recorder
after Action was used to inspect and drive the full interaction sequence.
